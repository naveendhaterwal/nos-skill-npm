# Contributing to nos-skill

We love your input! We want to make contributing to `nos-skill` as easy and transparent as possible, whether it's:

- Reporting a bug
- Discussing the current state of the code
- Submitting a fix
- Proposing new features
- Adding new skills to the official registry

## Development Process

We use GitHub to sync our code and use GitHub issues to track bugs and features.

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes (`npm test`).
5. Make sure your code lints.
6. Issue that pull request!

## Any questions?

Feel free to open an issue or reach out to the Nosana team.
